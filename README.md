# Prediksi PM2.5 Menggunakan Random Forest

## Deskripsi

Project ini merupakan studi kasus Machine Learning untuk memprediksi
konsentrasi PM2.5 menggunakan dataset Beijing PM2.5 dari Kaggle.

## Dataset

Dataset yang digunakan adalah Beijing PM2.5 Dataset.

## Metode

Model Machine Learning yang digunakan:

- Random Forest Regressor

## Fitur

Fitur yang digunakan meliputi:

- Year
- Month
- Day
- Hour
- DEWP
- TEMP
- PRES
- Wind Speed
- Snow
- Rain
- Wind Direction

## Target

Target yang diprediksi:

PM2.5

## Evaluasi

Model dievaluasi menggunakan:

- MAE
- RMSE
- R² Score

## Teknologi

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Google Colab
